Seasonal Forecast — All Categories

Holt-Winters triple exponential smoothing (same family of method as Excel's FORECAST.ETS): trend + 12-month seasonality, fitted fresh on every load so the forecast always reflects the latest published data.

How to read this: each series is fit with Holt-Winters exponential smoothing (level + trend + seasonal components, optimized over a parameter grid to minimize in-sample error), then projected forward. This is the same technique family behind Excel's FORECAST.ETS — not a guaranteed identical output, since Excel's exact ETS model-selection differs internally, but built on the same trend + seasonality logic and meant to be directionally consistent with it. Treat this as a planning input, not a guarantee — real PPI moves are driven by events (tariffs, energy shocks, supply disruptions) that no smoothing model sees coming.
